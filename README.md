# ТИХИЙ ГОРОД — симулятор мера маленькой русской провинции

Пиксельная уютная градостроительная игра про Россию 2026 года.
Ты — мэр маленького города. Здесь **нет победы и поражения** — есть город,
люди, бензин по талонам, тарифы ЖКХ, первый снег и душевность.

## Запуск

```bash
cd game
python3 -m http.server 8000 --bind 0.0.0.0
# открой http://localhost:8000
```

Или любой статический сервер. Сборка не нужна — чистый веб (canvas + WebGL пост-обработка).

## Управление

- **ЛКМ** — построить / поговорить (клик по жителю — узнаешь его мысли)
- **ПКМ / Esc** — убрать инструмент
- **WASD / стрелки** — камера
- Кнопки сверху: звук (атмосферный эмбиент: ветер, птицы, колокол), пауза, меню

## Что внутри

- **160 AI-сгенерированных пиксельных спрайтов** (листовая нарезка с magenta-кеингом,
  premultiplied-alpha даунскейл): дома (хрущёвки, избы, коттеджи), город (храм, ДК,
  котельная, водонапорка), экономика (АЗС, рынок, пекарня, завод), машины (лада,
  маршрутка, КАМАЗ, снегоуборочная), люди, коты, декор, UI-иконки.
- **Смена времён года** (снег, листопад, дождь, светлячки летом), **день/ночь**
  с динамическим освещением: фонари, окна, фары.
- **WebGL-шейдеры**: bloom, тёплый грейдинг, виньетка, плёночное зерно, сканлайны,
  лёгкая хроматическая аберрация.
- **Живой город**: жители гуляют и думают свои мысли, туристы приезжают за
  «русскостью» и фотографируют колодец, машины и автобус ездят по дорожной сети (BFS).
- **Экономика 2026**: бюджет, налоги, инфляция, высокая ключевая ставка, дефицит
  кадров, износ сетей ЖКХ, лимиты бензина «30 литров в одни руки», внутренний туризм.
- **События по мотивам новостей 2020–2026** с выборами: топливный кризис и Евро-3,
  индексация тарифов, прорыв трубы, Масленица, первый снег, коты на рынке.
- **Душевность** вместо очков: скамейки, пекарни, качели и коты важнее KPI.
- Автосохранение в localStorage.

## Структура

```
game/            игра (index.html, js/, css/, assets/)
  js/main.js     бут, ввод, игровой цикл
  js/world.js    карта, дороги, постройки
  js/sim.js      экономика, агенты, погода
  js/render.js   рендер мира, освещение
  js/postfx.js   WebGL пост-обработка
  js/data.js     постройки, события, новости (по реальным сюжетам 2020–2026)
  js/audio.js    процедурный эмбиент (WebAudio)
tools/slice.py   нарезка AI-листов в спрайты + manifest.json
tools/test/      headless-тесты (jsdom + программный canvas): логика и покадровый рендер
raw/             исходные AI-листы (вне git, см. .gitignore)
```

## Тесты

```bash
cd tools/test && npm i && node run.mjs   # логика: бут, стройка, экономика, save/load
node vis.mjs                              # рендер реальных кадров в /tmp/frame_*.png
```
